# Brad's Multi-Tool — notes for Claude

- This plugin will be published on the RuneLite Plugin Hub. Every change must pass its review:
  check docs/PLUGIN_HUB_COMPLIANCE.md before adding features or code, and update it when something
  changes. In short: no reflection, no Thread.sleep/interrupt, no java.io file APIs, no own Gson/OkHttp,
  no menuAction/runScript, LinkBrowser.browse only, nothing that acts for the player or breaks Jagex's
  third-party client guidelines. When the user asks for something that would break these, say so.
- Commit messages end with the attribution lines from the session; no model names in commits or code.
- Data files in src/main/resources are generated by scripts/ (OSRS Wiki, RuneLite source); regenerate
  rather than hand-editing.
