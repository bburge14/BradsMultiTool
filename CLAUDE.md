# Snuffy's Multi-Tool — notes for Claude

- This plugin will be published on the RuneLite Plugin Hub. Every change must pass its review:
  check docs/PLUGIN_HUB_COMPLIANCE.md before adding features or code, and update it when something
  changes. In short: no reflection, no Thread.sleep/interrupt, no java.io file APIs, no own Gson/OkHttp,
  no menuAction/runScript, LinkBrowser.browse only, nothing that acts for the player or breaks Jagex's
  third-party client guidelines. When the user asks for something that would break these, say so.
- Commit messages end with the attribution lines from the session; no model names in commits or code.
- Data files in src/main/resources are generated by scripts/ (OSRS Wiki, RuneLite source); regenerate
  rather than hand-editing.
- The features will be split into separate plugins (docs/DEVELOPMENT.md "Planned: separate plugins"): keep each one
  self-contained: Snuffy's Skill Tracker (tracker, goals, suggestions and the skilling helpers), Snuffy's
  PvM & Slayer, Snuffy's Gemstone Crab, and an optional Snuffy's Voices. Each plugin ships its own voice
  lines (voices/<voice>/<plugin>/, VoiceAlertService.VoicePlugin) and their settings sit with its feature.
- docs/DEVELOPMENT.md "How the code is split" has the rules that keep each plugin standalone; after changes,
  run `python3 scripts/split_plugins.py --verify` (each plugin must compile on its own) as well as the tests.
- The brand players see is "Snuffy's". The code keeps its old names (package com.bradsmultitool, config
  group "bradsmultitool": renaming the group would wipe players' saved settings and goals).
- README.md is for players: features and how to run it. Developer notes (data files, the plugin split,
  previews) go in docs/DEVELOPMENT.md.
